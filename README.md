## About Smriti

Smriti is an AI powered memory gaming and reminder companion
mobile app designed for elderly dementia patients across the
North Eastern Region of India.

It combines memory games, everyday reminders, and caregiver
support in one simple mobile experience.

The app is designed to speak familiar languages, reflect local
culture, and support core patient activities offline.

---

## The Problem

Elderly users and their families in remote areas can face
barriers to accessing ongoing cognitive support.

These include:

- Limited access to specialist services.
- Unreliable internet connectivity.
- Language barriers in digital applications.
- Complicated interfaces and small controls.
- Activities that feel unfamiliar to local users.

Smriti aims to address these challenges through an accessible,
voice-first, and culturally familiar mobile experience.

---

## Our Solution

### 1. Play & Learn

A patient-focused experience with memory, attention, and
recall games.

- Themes inspired by tea gardens, festivals, and local life.
- Simple touch based interactions.
- Large tap targets.
- Adaptive difficulty designed around game performance
  and reaction times.

### 2. Gentle Reminders

Voice-first reminders designed to support everyday routines.

- Medicine reminders.
- Hydration and meal reminders.
- Prompts for family calls.
- Spoken guidance using supported mobile voice engines.

### 3. Caregiver Dashboard

A dedicated view designed to help family members follow
patient activity and engagement.

- Review game activity and performance.
- View engagement trends over time.
- Identify changes that may need attention.
- Synchronize updates when internet connectivity is available.

## Key Design Priorities

| Priority | Our Approach |
| --- | --- |
| Accessibility | Simple navigation and large tap targets |
| Language | Regional language support and voice guidance |
| Connectivity | Offline access to core patient activities |
| Familiarity | Local foods, festivals, and cultural themes |
| Caregiving | Games, reminders, and caregiver insights together |
| Adaptability | Difficulty based on gameplay performance |

---

## Offline Support

Smriti is designed to keep core patient activities available
without a constant internet connection.

- Game activity is stored locally on the device.
- Caregiver synchronization requires internet access.
- Offline voice features depend on available language models
  or installed voice packs.
- Local scheduled reminders can work offline; remote push
  notifications require connectivity.
